# Batto OBS Tool

Offizielles Hauptrepository für **Batto OBS Tool** von **Crazy_Batto / Team Alpha**.

## Aktueller Fokus

Die Windows-Version wird zuerst vollständig fertiggestellt und geprüft. Die Handy-App bleibt Bestandteil des Gesamtsystems, wird aber erst nach dem stabilen Windows-Meilenstein weiterentwickelt.

## Entwicklungsregeln

- Produktname ausschließlich **Batto OBS Tool**
- ausschließlich Crazy_Batto-/Team-Alpha-Branding
- keine alten Produktnamen oder fremden Logos
- Windows-Installer mit frei wählbarem Installationspfad
- echte OBS-, Hardware- und Netzwerkdaten; keine erfundenen Messwerte
- transparente OBS-Browserquellen
- Touch-Deck-Belegungen dürfen bei Rasteränderungen nicht verloren gehen
- Plugins werden nach Fertigstellung der Windows-Grundfunktionen weiterbearbeitet

## Branches

- `main`: geprüfter stabiler Stand
- `feat/windows-1.9.0`: aktive Entwicklung der Windows-Version 1.9.0
