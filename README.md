# Batto OBS Tool

Offizielles Hauptrepository für **Batto OBS Tool** von **Crazy_Batto / Team Alpha**.

## Downloadstatus

**Für Version 1.9.0 ist derzeit noch kein Windows-Installer als GitHub-Release oder Actions-Artefakt veröffentlicht.**

Der Quellcode-Download von GitHub ist kein Installer. Ein Windows-Paket wird hier erst als fertig bezeichnet, wenn die vollständige Desktop-Anwendung gebaut, installiert, gestartet und anschließend als echtes Release-Asset hochgeladen wurde.

Der letzte tatsächlich veröffentlichte Windows-Download ist der ältere Stand **Batto OBS Tool 1.8.7** im bisherigen privaten Repository:

- https://github.com/dannymeienbrock99-prog/CrazyBattoSoftwareManager_vol.1/releases/tag/batto-obs-tool-v1.8.7

Für diesen privaten Download muss das berechtigte GitHub-Konto angemeldet sein. Version 1.8.7 enthält nicht automatisch die später im neuen Repository entwickelten Module.

## Aktueller Fokus

Die Windows-Version wird zuerst vollständig fertiggestellt und geprüft. Die Handy-App bleibt Bestandteil des Gesamtsystems, wird aber erst nach dem stabilen Windows-Meilenstein weiterentwickelt.

## Entwicklungsregeln

- Produktname ausschließlich **Batto OBS Tool**
- ausschließlich Crazy_Batto-/Team-Alpha-Branding
- keine alten Produktnamen oder fremden Logos
- Windows-Installer mit frei wählbarem Installationspfad
- echte OBS-, Hardware- und Netzwerkdaten; keine erfundenen Messwerte
- transparente OBS-Browserquellen
- Touch-Deck-Belegungen dürfen bei Rasteränderungen nicht verloren gehen
- Plugins werden nach Fertigstellung der Windows-Grundfunktionen weiterbearbeitet
- keine Download- oder Erfolgsmeldung ohne vorhandenes und geprüftes Release-Asset
